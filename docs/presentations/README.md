# CareFit 발표 자료

캡스톤 디자인 II 발표용 자료 모음. 두 가지 형식의 자료가 있음.

## 파일 안내

### 발표용 자료 (슬라이드별 + 발표자 대사)

PPT를 슬라이드별로 만들 때 그대로 옮기면 되는 형식.

| 파일 | 용도 | 분량 | 슬라이드 |
|---|---|---|---|
| [`01-overview.md`](01-overview.md) | 1차 — 소개 + 진행 | 5분 | 7~8장 |
| [`02-features.md`](02-features.md) | 2차 — 핵심 기능 구현 | 7분 | 9~10장 |
| [`03-final.md`](03-final.md) | 3차 — 최종 + 배포 | 8분 | 9~10장 |

### 한글 문서 자료 (팀원이 자유롭게 PPT 제작용)

내용을 글로 풀어 쓴 형태. 팀원이 읽고 본인 스타일대로 PPT를 자유롭게 만들 때 사용.

| 파일 | 용도 |
|---|---|
| [`handout-01.md`](handout-01.md) | 1차 발표 분량 한글 풀어쓰기 |
| [`handout-02.md`](handout-02.md) | 2차 발표 분량 한글 풀어쓰기 |
| [`handout-03.md`](handout-03.md) | 3차(최종) 발표 분량 한글 풀어쓰기 |

### 최종 대본

| 파일 | 용도 |
|---|---|
| [`full-script.md`](full-script.md) | 졸업 작품 수준 최종 대본 (9~10분 분량, 실제 낭독용) |

## 두 형식의 차이

```
[발표용 자료 (01/02/03)]
─────────────────────────
- 슬라이드 한 장씩 정확히 나뉨
- 각 슬라이드의 핵심 메시지, 불릿, 도표, 발표자 대사
- 그대로 PPT 슬라이드 한 장씩 만들면 끝

[한글 문서 자료 (handout-01/02/03)]
─────────────────────────
- 글로 풀어쓴 형식 (소설처럼 읽힘)
- 팀원이 읽고 본인 스타일대로 PPT 자유 제작
- 한글 파일로 출력해서 공유 가능
```

## 사용 가이드

### 팀원에게 자료 전달 시
1. **PPT 슬라이드 단위로 만들고 싶다** → 발표용 자료 (01/02/03)
2. **글로 먼저 읽고 본인이 자유롭게 만들고 싶다** → handout (01/02/03)
3. **실제 발표 대본이 필요하다** → full-script.md

### 발표 연습 시
- `full-script.md`를 천천히 읽으며 시간 측정
- 라이브 시연 부분은 실제 화면을 띄워두고 연습
- 부록의 자주 들어올 질문에 대한 답변도 미리 숙지

## 발표 구성 의도

3번 발표를 하나의 흐름으로 연결:

```
[1차]                     [2차]                     [3차]
─────                     ─────                     ─────
프로젝트의 "왜"     →     "어떻게 동작"        →    "결과 + 의미"
배경, 차별점,             AI 분석, 라이브 시연,     배포 환경 시연,
기술 스택, 진행           기능별 디테일             성과, 사용자 의미, 향후
```

- **1차**: 청중이 처음 들어도 무엇이고 왜 만들었는지 알 수 있게
- **2차**: 기술적 깊이 + 라이브 시연으로 "되는구나" 보여줌
- **3차**: 결과 + 사용자 의미 부각 + 미래 비전으로 임팩트 있게 마무리

## 시각 자료 준비 체크리스트

PPT 만들 때 미리 준비하면 좋을 자료들:

- [ ] **앱 로고 / 메인 화면** 스크린샷
- [ ] **MoveNet 키포인트 17개** 다이어그램
- [ ] **각도 계산 수식 + 운동 예시** (앉아서 앞으로 나란히)
- [ ] **자세 사이클 state machine** 도식
- [ ] **운동 가이드 화면** (4섹션) 스크린샷
- [ ] **카카오 로그인 → 모달** 흐름 스크린샷
- [ ] **기록 화면** 스크린샷 (목표 / 막대그래프 / 운동별 카드)
- [ ] **전체화면 모드** 스크린샷
- [ ] **시스템 구조도** (브라우저 / 백엔드 / DB)
- [ ] **배포 구조도** (nginx / Spring / postgres 컨테이너)
- [ ] **통계 인포그래픽** (장애인 병원 미방문 36.5% / 6만 4천 원)

## 데모 동영상 (선택)

라이브 시연이 불안하면 백업용 데모 영상 1~2분짜리 준비해두면 안전.
- 카카오 로그인 → 운동 → 결과 → 기록 까지 흐름
- 화면 녹화 + 자막 (간단한 캡션)
- 발표장 인터넷이 불안할 경우 로컬 파일로 재생
