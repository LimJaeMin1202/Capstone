# 1차 발표 자료 (한글 문서)

> 팀원이 이 글을 읽고 본인 스타일대로 PPT를 제작할 수 있도록 풀어쓴 자료.
> 1차 발표는 약 5분 — 프로젝트의 **배경과 차별점**을 명확히 전달하는 데 집중.

---

## 1. 우리가 무엇을 만들었는가

저희가 만든 시스템의 이름은 **CareFit**입니다. 한 줄로 설명하자면, **고령자와 장애인이 가정에서 웹캠 하나로 재활 운동을 할 수 있도록 돕는 AI 자세 피드백 웹 시스템**입니다.

사용자는 본인 컴퓨터나 노트북 앞에 앉아서, 화면에 표시되는 운동을 따라 합니다. 카메라가 사용자의 모습을 보고, AI가 매 프레임마다 관절의 각도를 측정해서 자세가 올바른지를 실시간으로 알려줍니다. 자세가 정확하면 초록색 메시지로 칭찬하고, 부족하면 빨간색으로 격려합니다.

기존의 재활 솔루션들이 고가의 장비나 병원 방문을 요구하는 것과 달리, 저희 시스템은 **이미 가지고 있는 컴퓨터와 카메라만으로** 충분합니다.

---

## 2. 왜 이 프로젝트를 시작했는가

### 사회적 약자의 재활 치료 접근성 문제

자료를 조사하면서 가장 충격적이었던 통계가 있습니다.

> 장애인이 병원을 가지 않는 가장 큰 이유 1위는 **이동이 불편해서** (36.5%) 입니다.

병이 없어서가 아니라, 갈 수 없어서 못 가는 것입니다. 재활 치료는 일회성이 아니라 지속적이고 반복적인 치료가 필요한데, 매번 병원에 가는 것 자체가 큰 벽이 됩니다.

여기에 경제적인 부담도 있습니다. 재활 치료 1회 평균 비용은 약 **6만 4천 원**. 일주일에 두세 번씩 치료를 받는다고 가정하면, 한 달에 50만 원이 넘는 돈이 들어갑니다.

### 기존 원격 재활 솔루션의 한계

물론 원격 재활 솔루션이 이미 존재합니다. 하지만 대부분이 **고가의 웨어러블 센서**나 전용 장비를 요구합니다. 가뜩이나 경제적으로 부담스러운 어르신들에게 또 다른 진입 장벽이 되는 셈입니다.

여기에 더해, 일반 시중의 헬스/필라테스 앱들은 **건강한 일반인 기준**으로 만들어져 있습니다. 어르신이나 장애인이 그 기준의 운동 강도를 따라하다 보면 부상 위험이 커지고, 결국 운동을 포기하게 됩니다.

### 그래서 우리는

- 별도 장비 없이 **이미 있는 웹캠만으로** 동작하고
- **사회적 약자에 맞춰 보수적으로 재조정된** 운동 기준을 적용하며
- AI가 매 순간 자세를 봐주는 **개인 트레이너 역할**을 하는

이런 시스템을 만들기로 했습니다.

## 3. 차별점

저희가 일반적인 헬스 앱과 다른 점을 네 가지로 정리할 수 있습니다.

**첫째, ROM(가동범위)을 보수적으로 재조정했습니다.**
일반인이라면 어깨를 90도까지 올려야 정상으로 인정받는 운동도, 어르신은 70도 정도면 충분하다고 봅니다. 무리하지 않으면서도 효과가 있는 의학적 최소 가동 범위를 기준으로 잡았습니다.

**둘째, 두 단계 판정 시스템입니다.**
"정상 도달"은 목표이고, "허용 도달"은 성공입니다. 어르신이 끝까지 못 가더라도 일정 범위에 도달하면 카운트가 올라가고 격려를 받습니다. 그래야 운동을 지속할 수 있습니다.

**셋째, 별도 장비가 필요 없습니다.**
웨어러블 센서도, 헬스장 회원권도 필요 없습니다. 가정의 컴퓨터와 카메라만 있으면 됩니다.

**넷째, AI가 매 프레임 관절 각도를 측정합니다.**
단순히 동영상을 보고 따라하는 게 아닙니다. AI가 사용자의 17개 관절을 인식하고, 운동에 필요한 세 점의 각도를 계산해서 매 순간 피드백을 줍니다.

## 4. 핵심 기능 미리보기

본격적인 기능 설명은 2차 발표에서 자세히 다룰 예정이지만, 1차에서는 큰 그림을 보여드리고자 합니다.

### 사용자 흐름

1. **로그인** — 일반 가입 또는 카카오톡으로 한 번 클릭 로그인
2. **운동 선택** — 29개 운동 중 부위별·난이도별로 선택
3. **운동 수행** — AI가 자세를 실시간 분석하며 피드백
4. **결과 확인** — 횟수, 시간, 정확도와 함께 축하 메시지
5. **기록 확인** — 주간 통계, 목표 진행률, 추세 그래프

### 운동 콘텐츠 구성

총 29개의 재활 운동을 세 가지 환경으로 나누어 준비했습니다.

- **의자에 앉아서 하는 운동** (12개) — 휠체어 사용자도 가능
- **벽이나 의자에 의지해서 하는 운동** (9개) — 균형 보조가 필요한 중급
- **바닥과 매트에서 하는 운동** (8개) — 코어와 유연성 위주의 고급

부위별로는 어깨, 팔, 가슴, 등·허리, 코어, 하체, 종아리·발목 등으로 분류되어 있고, 난이도별로도 초·중·고급으로 정렬할 수 있습니다.

## 5. 기술 스택

저희가 선택한 기술과 그 이유를 간단히 설명드립니다.

**AI 모델**로는 **TensorFlow.js**의 **MoveNet Lightning**을 사용했습니다. 이 모델의 가장 큰 장점은 **브라우저에서 직접 돌아간다**는 점입니다. 즉, 사용자의 영상이 서버로 전송되지 않습니다. 프라이버시 보호와 서버 비용 절감이라는 두 마리 토끼를 잡을 수 있습니다.

**프론트엔드**는 **React + TypeScript + Vite + React Router**로 구성했습니다. 화면을 컴포넌트 단위로 모듈화하고, 타입스크립트로 백엔드와 데이터 형식을 일관되게 맞췄습니다.

**백엔드**는 **Spring Boot 4.0.6**과 **Spring Data JPA**를 사용했습니다. 한국 취업 시장의 표준이라 학습 자료가 풍부하고, JPA를 통해 SQL을 최소화할 수 있다는 장점이 있습니다.

**인증**은 **JWT 기반의 stateless 방식**입니다. 클라이언트와 서버가 분리된 환경에서 가장 적합한 선택이었습니다.

**소셜 로그인**은 **카카오 OAuth**를 적용했습니다. 어르신들의 카카오톡 사용률이 매우 높다는 점을 고려한 결정입니다.

**데이터베이스**는 **PostgreSQL 16**, **배포**는 **Docker Compose**를 사용했습니다.

## 6. 개발 진행 상황

현재까지 완료된 작업과 남은 작업을 정리하면 다음과 같습니다.

**완료된 것**
- 핵심 기능 1차 구현 (1학기 캡스톤에서)
- 카카오 로그인과 출생연도 입력
- 어르신 친화 운동 가이드 (4섹션 구조)
- 자세 사이클 기반 횟수 카운트 로직
- 운동 기록 통계와 목표 설정 기능
- 유지 동작(플랭크 등) 별도 처리
- 모바일 반응형 UI
- React Router 도입과 주차별 기록 조회
- 영상 전체화면 모드
- Docker 배포 틀

**남은 것**
- 연구실 서버에 실제 배포
- HTTPS 적용 (모바일 카메라 권한 위해)
- 최종 시연과 마무리

## 부록 — PPT 제작 팁

이 자료를 토대로 PPT를 만들 때 참고할 수 있는 팁입니다.

- **표지** + **목차** + **본문 5~6장** + **마무리** 정도가 5분 발표에 적합합니다
- 통계 수치(36.5%, 6만 4천 원 등)는 **인포그래픽**으로 시각화하면 임팩트가 큽니다
- 차별점 비교 표는 **2단 표**로 깔끔하게 만들 수 있습니다
- 기술 스택은 **아이콘 + 이름** 조합으로 한 슬라이드에 배치하는 게 일반적입니다
- 진행 상황은 **체크리스트**나 **타임라인** 형식이 직관적입니다
