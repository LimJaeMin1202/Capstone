# 1차 발표 — 프로젝트 소개 + 진행 보고

> 분량: 약 5분 / 슬라이드 7~8장 기준
> 목적: 프로젝트의 **배경과 차별점**을 명확히 전달.
> 팀원이 이 자료를 토대로 PPT 슬라이드를 만들면 됨.

---

## 슬라이드 1 — 표지

**제목**: CareFit — AI 재활 운동 자세 피드백 시스템
**부제**: 사회적 약자를 위한 가정용 재활 솔루션
**팀**: 임재민 / 유성희 / 정서연

**대사**:
> 안녕하십니까. AI 자세 피드백을 활용한 가정용 재활 시스템, CareFit을 발표하는 N팀입니다.

---

## 슬라이드 2 — 문제 배경

**핵심 메시지**: 사회적 약자가 가정에서 재활을 지속하기 어렵다

**불릿**:
- 장애인 병원 미방문 이유 1위: **이동 불편 (36.5%)**
- 재활 치료 1회 평균 **6만 4천 원** — 반복 부담
- 기존 원격 솔루션은 **고가 웨어러블** 필요
- 어르신은 **복잡한 기기 조작** 자체가 어려움

**시각 자료 추천**: 통계 인포그래픽 1장

**대사**:
> 거동이 불편한 어르신과 장애인분들이 병원을 못 가는 가장 큰 이유는 이동 자체가 어렵기 때문입니다. 한 번에 6만 원이 넘는 치료비도 부담이고요. 기존 원격 재활 솔루션은 고가의 웨어러블 장비가 필요해서 결국 또 진입 장벽이 됩니다.

---

## 슬라이드 3 — 해결책 한 줄

**핵심 메시지**: 웹캠 하나로, AI가 자세를 실시간 분석

**대사**:
> 그래서 저희는 **별도 장비 없이 웹캠만으로** 가정에서 재활 운동을 할 수 있고, AI가 관절 각도를 분석해 실시간 자세 교정을 해주는 웹 시스템을 만들었습니다.

---

## 슬라이드 4 — 기존 헬스 앱과의 차별점

**비교 표**:
| 기존 헬스/필라테스 앱 | CareFit |
|---|---|
| 일반인 기준 강한 ROM | 고령자·장애인 맞춤 보수적 ROM |
| 정확한 자세 강요 → 부상·좌절 | 정상/허용 두 단계로 동기 + 안전 |
| 헬스장·웨어러블 의존 | 웹캠만 있으면 즉시 |
| 단순 영상 가이드 | AI가 매 프레임 관절 각도 측정 |

**대사**:
> 일반 헬스 앱과의 가장 큰 차이는 두 가지입니다. 첫째, 일반인이 아닌 **사회적 약자에게 안전한 가동 범위**로 운동 기준을 재조정했다는 점. 둘째, "정상 도달"과 "허용 도달" **두 단계로 판정**해서 무리하지 않아도 성공할 수 있게 한 점입니다.

## 슬라이드 5 — 핵심 기능 5가지

**불릿**:
1. 회원가입 / **카카오 로그인** (어르신 친화)
2. 29개 재활 운동, 3가지 카테고리
3. **AI 실시간 자세 분석** (MoveNet, 브라우저 자체 실행)
4. **자세 사이클 기반 횟수 카운트** (잡고 풀어야 1회)
5. 주간 기록 + 목표 설정 + 통계

**대사**:
> 핵심 기능은 다섯 가지입니다. 카카오 로그인, 29개 운동, 실시간 자세 분석, 자세 사이클 카운트, 그리고 주간 기록 시각화입니다. 각 기능을 뒤에서 자세히 보여드리겠습니다.

---

## 슬라이드 6 — 기술 스택

**도표**:
- AI: TensorFlow.js + MoveNet Lightning
- 프론트: React + TypeScript + Vite + React Router
- 백엔드: Spring Boot 4.0.6 + Spring Data JPA
- 인증: Spring Security + JWT + 카카오 OAuth
- DB: PostgreSQL 16
- 배포: Docker Compose + nginx

**대사**:
> 기술 스택은 표준에 가깝습니다. 다만 AI 모델은 브라우저에서 직접 돌아가는 **TensorFlow.js + MoveNet Lightning**을 선택했는데, 이렇게 하면 영상이 서버로 안 가니까 프라이버시도 지키고 서버 부담도 0입니다.

**완료된 것**:

**대사**:
