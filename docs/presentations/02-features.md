## 슬라이드 2 — AI 자세 분석 동작 원리

**핵심 메시지**: MoveNet으로 관절 인식 → 세 점 각도 계산 → 단계별 판정

**불릿**:
1. MoveNet Lightning이 매 프레임 **17개 관절** 키포인트 추출
2. 운동마다 정해진 **세 점(A-B-C)** 의 각도 계산
   - 예) "앉아서 앞으로 나란히" → 고관절-어깨-팔꿈치
3. 단계별 판정: 미달(빨강) / 허용(연두) / 정상(초록)

**시각 자료**: 키포인트 17개 다이어그램 + 각도 계산 수식

**대사**:
> AI는 매 프레임에서 관절 17개를 인식합니다. 운동마다 정해진 세 점의 좌표로 각도를 계산하는데요, 예를 들어 "앉아서 앞으로 나란히"는 고관절-어깨-팔꿈치의 각도가 0도에서 시작해 90도까지 올라가는 게 정상이고, 60도만 올려도 허용 범위로 인정합니다. 이 두 단계 판정이 어르신에게 부상 없이 성공 경험을 만들어주는 핵심입니다.

## 슬라이드 3 — 자세 사이클 기반 횟수 카운트

**핵심 메시지**: 운동의 본질(잡기 → 유지 → 풀기)을 반영

**도식**:
```
[rest]                       (휴식 자세)
   │ 운동 자세 진입
   ▼
[holding]                    (유지 중, 카운트다운 표시)
   │ 목표 시간 충족
   ▼
[satisfied]                  (✨ 충분! 천천히 풀기)
   │ 자세 풀고 400ms 지속
   ▼
[rest] + count + 1           ← 1회 카운트
```

**대사**:
> 처음 만들었을 때는 "정자세 0.8초 유지하면 카운트"였는데, 카메라가 잠깐 흔들리면 카운트가 잘못 올라가는 등 노이즈에 약했습니다. 그래서 운동의 본질인 "잡기-유지-풀기" 사이클을 그대로 모델링한 3단계 state machine을 만들었습니다. 잡고만 있어도 카운트는 안 되고, **풀어야** 1회로 셈됩니다. 키포인트가 한두 프레임 흔들려도 그레이스 윈도우 300ms로 흡수합니다.

## 슬라이드 4 — 유지 동작 별도 처리

**핵심 메시지**: 플랭크처럼 한 자세를 길게 유지하는 운동은 다른 측정

**비교**:
| | rep 모드 (28개 운동) | hold 모드 (플랭크) |
|---|---|---|
| 카운트 | 운동 횟수 | 누적 유지 시간 |
| UI | "운동 횟수 N회" | "총 유지 시간 N초" |
| 동작 | 잡고 풀고 반복 | 한 번 잡고 가능한 오래 |

**대사**:
> 모든 운동을 같은 방식으로 다룰 수는 없었습니다. 플랭크는 횟수가 의미 없고 **얼마나 오래 유지했는지**가 본질입니다. 그래서 운동마다 `rep` 또는 `hold` 모드를 지정하고, hold 모드일 때는 우측 패널에 "누적 유지 시간"이 매초 늘어나도록 했습니다.

## 슬라이드 5 — 운동 가이드 (어르신 친화)

**4섹션 구조**:
- 📌 준비 자세
- 👣 따라하기 (단계별 번호 ①②③)
- ⚠️ 주의 사항 (노란 박스)
- 💪 어떤 효과가 있나요?

**추가 안내**: 카메라 위치 (정면/측면) 자동 표시

**대사**:
> 운동 가이드는 어르신 언어로 다시 썼습니다. "어깨충돌증후군"같은 의학용어 대신 "어깨 부딪힘"으로, 단계별 번호로, 주의사항은 노란 박스로 강조했습니다. 운동마다 어디서 카메라를 봐야 정확한지도 자동으로 안내합니다.

## 슬라이드 6 — 카카오 로그인 + 출생연도

**플로우**:
1. 카카오 OAuth 인가코드 받기
2. 백엔드에서 토큰 교환 + 사용자 정보 조회
3. 신규면 자동 가입 (`kakao_<id>`, password=null)
4. JWT 발급
5. 첫 로그인 시 **출생연도 모달** (큰 10년대 버튼)

**대사**:
> 어르신은 카카오톡 사용률이 매우 높습니다. 그래서 한 번 클릭으로 가입할 수 있게 카카오 로그인을 핵심으로 넣었습니다. 카카오에서 출생연도를 받으려면 비즈 앱 검수가 필요해서, 첫 로그인 후 모달로 직접 받습니다. 입력은 1950년대 같은 **큰 버튼** 7개 중 하나 고르면 끝입니다.

## 슬라이드 7 — 기록 + 목표 (주간 시각화)

**구성**:
1. **이번 주 목표 진행바** (운동 횟수 / 시간)
2. **요약 4카드**: 이번주 횟수, 시간, 평균 정확도, 연속 운동일
3. **주간 추세 막대그래프** — 최근 7일
4. **운동별 카드** — 어떤 운동을 얼마나 했는지
5. **주차 이동 가능** — 이전 주, 그 전 주도 모두 조회

**대사**:
> 운동을 끝내면 자동 저장되고 기록 화면에서 시각화됩니다. 이번 주 목표 진행바, 4개 요약 카드, 7일 막대그래프, 운동별 카드. **주차 이동 버튼**으로 한 달 전 기록까지 다 확인할 수 있습니다. 사용자가 "내가 꾸준히 하고 있구나"를 한눈에 보게 만드는 게 목표였습니다.

## 슬라이드 8 — 어르신 친화 UI

**불릿**:
- 글씨 크기 토글 (작게 / 보통 / 크게) — PC/모바일 분리 매핑
- 차분한 세이지 그린 색감
- **색상 기반 피드백** (글을 못 읽어도 색으로 인지)
- 한국어 어절 단위 줄바꿈
- 로그아웃은 설정 모달 안에 (잘못 누름 방지)
- 모바일 반응형 (네비바 점진적 축소)

**대사**:
> 어르신 시력을 고려해서 글씨 크기를 직접 조절할 수 있고, PC와 모바일에서 각각 다른 px로 매핑됩니다. 색상으로도 피드백을 주기 때문에 글을 안 읽어도 빨강/노랑/초록으로 잘하고 있는지 알 수 있습니다. 로그아웃은 잘못 누르면 곤란하니까 설정 모달 안쪽으로 빼서 두 번 클릭하게 만들었습니다.

## 슬라이드 9 — 라이브 시연

**시연 시나리오**:
1. 카카오 로그인 → 연령대 입력 모달
2. 운동 선택 (앉아서 앞으로 나란히)
3. 카메라 안내 → 시작
4. 자세 잡고 → 카운트다운 → 풀고 → 1회 카운트
5. 운동 완료 → 결과 화면
6. 기록 보기 → 목표 진행바 + 주간 추세

**대사**:
> 실제로 한번 보여드리겠습니다.
