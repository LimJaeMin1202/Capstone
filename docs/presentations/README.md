# CareFit 발표 자료

캡스톤 디자인 II 발표용 자료 모음. 팀원들이 이 자료를 토대로 PPT를 만들면 됨.

## 파일 안내

| 파일 | 용도 | 분량 | 슬라이드 |
|---|---|---|---|
| [`full-script.md`](full-script.md) | **전체 대본** (앱 모든 정보) | 10분 | - |
| [`01-overview.md`](01-overview.md) | 1차 발표 — 소개 + 진행 | 5분 | 7~8장 |
| [`02-features.md`](02-features.md) | 2차 발표 — 핵심 기능 구현 | 7분 | 9~10장 |
| [`03-final.md`](03-final.md) | 3차 발표 — 최종 + 배포 | 8분 | 9~10장 |

## 사용 방법

### 팀원 PPT 작업 시
1. 발표 회차에 맞는 마크다운 파일 열기 (예: `01-overview.md`)
2. 슬라이드별로 나뉘어 있으니 그대로 PPT 슬라이드 1장씩 만들기
3. **시각 자료 추천** 표시된 곳에 인포그래픽/스크린샷 삽입
4. **대사** 부분은 발표자 노트에 그대로 붙여넣기

### 발표 연습 시
- `full-script.md`만 외워두면 1·2·3차 모두 자연스럽게 연결됨
- 각 회차 자료는 그중 일부를 발췌·확장한 버전

## 발표 구성 의도

3번 발표를 하나의 흐름으로 연결:

```
[1차]                          [2차]                          [3차]
─────                          ─────                          ─────
프로젝트의 "왜"          →     "어떻게 동작"               →   "최종 결과 + 다음"
배경, 차별점,                  AI 분석 디테일,                 배포된 라이브,
기술 스택, 진행 보고           기능별 라이브 시연              성과, 향후 계획
```

- **1차**: 청중이 처음 들어도 무엇이고 왜 만들었는지 알 수 있음
- **2차**: 기술적 깊이 + 라이브 시연으로 "되는구나" 보여줌
- **3차**: 마무리 + 다음 방향으로 임팩트 있게 끝냄

## 시각 자료 준비 체크리스트

PPT 만들 때 미리 준비하면 좋을 자료들:

- [ ] **앱 로고 / 메인 화면** 스크린샷
- [ ] **MoveNet 키포인트 17개** 다이어그램
- [ ] **각도 계산 수식 + 운동 예시** (앉아서 앞으로 나란히)
- [ ] **자세 사이클 state machine** 도식
- [ ] **운동 가이드 화면** (4섹션) 스크린샷
- [ ] **카카오 로그인 → 모달** 흐름 스크린샷
- [ ] **기록 화면** 스크린샷 (목표 / 막대그래프 / 운동별 카드)
- [ ] **시스템 구조도** (브라우저 / 백엔드 / DB)
- [ ] **배포 구조도** (nginx / Spring / postgres 컨테이너)
- [ ] **통계 인포그래픽** (장애인 병원 미방문 36.5% 등)

## 데모 동영상 (선택)

라이브 시연이 불안하면 백업용 데모 영상 1~2분짜리 준비해두면 안전.
- 카카오 로그인 → 운동 → 결과 → 기록 까지 흐름
- 화면 녹화 + 자막 (간단한 캡션)
