# CareFit — 완성 버전 전체 발표 대본

> 앱 전체를 처음부터 끝까지 설명하는 풀버전 대본.
> 1·2·3차 발표 자료의 원본이 되는 글. 약 10분 분량 기준.

---

## 1. 인사 + 프로젝트 한 줄 소개

> 안녕하십니까. **CareFit** 팀입니다. 저희가 만든 시스템은 **고령자와 장애인 같은 사회적 약자가 가정에서 웹캠 하나로 재활 운동을 할 수 있도록 돕는 AI 자세 피드백 웹 시스템**입니다.

---

## 2. 문제 배경

> 거동이 불편한 어르신과 장애인분들은 병원 방문 자체가 어려워서 재활 치료를 지속하기 힘듭니다.
> - 장애인 병원 미방문 이유 1위가 **이동 불편 36.5%**
> - 재활 치료 1회 평균 **6만 4천 원**으로 반복 치료 부담이 큽니다
> - 기존 원격 재활 솔루션은 **고가의 웨어러블 장비**가 필요해서 진입 장벽이 높습니다
> - 일반 헬스 앱은 **정상인 기준의 가동 범위**여서 부상 위험이 있고요
>
> 그래서 **별도 장비 없이 웹캠만으로** 가정에서 재활 운동을 할 수 있고, **사회적 약자 맞춤 기준**으로 자세를 분석해 실시간 피드백을 주는 시스템이 필요하다고 봤습니다.

---

## 3. 기존 솔루션 대비 차별점

> 저희는 네 가지를 차별화했습니다.
> 1. 일반인 기준이 아니라 **고령자·장애인에게 안전한 가동 범위**로 ROM을 보수적으로 재조정했습니다
> 2. 정상 도달 / 허용 도달 **두 단계 판정**으로 안전과 동기 부여를 모두 잡았습니다
> 3. 헬스장이나 웨어러블 없이 **웹캠만 있으면** 가정에서 즉시 사용 가능합니다
> 4. AI가 매 프레임 관절 각도를 측정해 **실시간 자세 교정**을 제공합니다

---

## 4. 주요 기능 (앱이 무엇을 하는가)

### 4-1. 회원가입 / 로그인

> 일반 아이디·비밀번호 가입과 **카카오 OAuth 로그인** 두 가지를 지원합니다.
> 어르신은 카카오톡 사용률이 높기 때문에 카카오 한 번 클릭으로 가입할 수 있게 했습니다.
> 가입 시 **출생연도(10년대 단위)** 를 큰 버튼으로 선택받아서, 향후 연령대별 운동 기준 적용에 활용합니다.

### 4-2. 운동 선택 (홈)

> 총 **29개의 재활 운동**이 들어있고, 세 가지 카테고리로 나눠집니다.
> - **의자 착석 12개** — 휠체어 사용자도 안전하게
> - **벽·의자 지지 9개** — 균형 보조가 필요한 중급
> - **바닥·매트 8개** — 코어와 유연성 위주의 고급
>
> 사용자는 자세별, 부위별, 난이도별로 운동을 정렬해 선택할 수 있습니다.

### 4-3. AI 자세 분석

> 핵심 기술은 **TensorFlow.js와 MoveNet Lightning 모델**입니다.
> 영상이 **서버로 전송되지 않고 브라우저에서 직접 처리**되기 때문에 프라이버시가 보호되고 서버 부담도 0입니다.
>
> MoveNet이 매 프레임에서 17개 관절을 인식하고, 운동마다 정해진 세 점 — 예를 들어 "앉아서 앞으로 나란히"라면 고관절-어깨-팔꿈치 — 의 각도를 계산합니다.
>
> 각도가 정상 목표에 도달하면 🎉 완벽, 허용 목표에 도달하면 👍 좋아요, 미달이면 격려 메시지가 색상과 함께 표시됩니다.

### 4-4. 자세 사이클 기반 횟수 카운트

> 운동의 본질은 "자세를 잡고, 유지하고, 푸는" 사이클이라고 보고 **3단계 state machine**을 만들었습니다.
> - `rest` — 휴식 자세
> - `holding` — 운동 자세에 들어와 시간을 채우는 중
> - `satisfied` — 목표 시간을 채웠으니 자세를 풀어달라고 안내
>
> 풀고 400ms 이상 지속되면 비로소 1회로 카운트됩니다.
> 이렇게 해서 **잡고 있기만 해서는 카운트가 안 되고**, 풀고 다시 잡아야 다음 카운트가 됩니다. 키포인트가 한두 프레임 흔들려도 그레이스 윈도우로 흡수합니다.
>
> 플랭크처럼 한 자세를 길게 유지하는 운동은 별도 **hold 모드**로 처리해서 횟수 대신 **총 유지 시간**을 측정합니다.

### 4-5. 운동별 가이드

> 각 운동마다 어르신이 보기 좋게 4섹션으로 가이드합니다.
> - 📌 준비 자세
> - 👣 따라하기 (단계별 번호)
> - ⚠️ 주의 사항
> - 💪 어떤 효과가 있나요?
>
> 의학용어 없이 일상어로 작성했고, **카메라 위치 안내**도 운동마다 정면 / 측면을 자동으로 표시합니다.

### 4-6. 실시간 운동 화면

> 운동 시작 버튼을 누르면 3-2-1 카운트다운 후 측정이 시작됩니다.
> 화면 좌측은 카메라 영상에 골격선이 실시간으로 그려지고, **자세 유지 카운트다운 배지**가 영상 우상단에 표시됩니다.
> 우측 패널에는 운동 횟수, 1회 유지 시간, 운동 시간, 현재 각도가 한눈에 보입니다.

### 4-7. 기록과 통계

> 운동을 완료하면 자동으로 결과가 저장되고, 기록 화면에서 시각화됩니다.
> - **이번 주 목표 진행바** — 횟수와 시간 두 가지
> - **주간 추세** — 최근 7일 막대그래프, 이전 주도 다 볼 수 있습니다
> - **요약 카드** — 운동 횟수, 시간, 평균 정확도, 연속 운동일
> - **운동별 카드** — 어떤 운동을 얼마나 했는지

### 4-8. 어르신 친화 UI

> - 글씨 크기를 **작게 / 보통 / 크게** 직접 조절 가능
> - PC와 모바일에서 각각 다른 px로 매핑 (모바일은 한 단계 작게)
> - 차분한 세이지 그린 색감
> - 색상 기반 피드백 (글을 못 읽어도 색으로 인지)
> - 한국어 어절 단위 줄바꿈
> - 카카오 가입자는 첫 로그인 시 출생연도 모달
> - 로그아웃은 설정 모달 안에 두어 잘못 누름 방지

## 5. 기술 스택

| 영역 | 기술 | 선택 이유 |
|---|---|---|
| AI 모델 | **TensorFlow.js + MoveNet Lightning** | 브라우저 자체 실행, 30~50fps |
| 프론트 | **React + TypeScript + Vite + React Router** | 컴포넌트 모듈화, 타입 안전 |
| 백엔드 | **Spring Boot 4.0.6 + Spring Data JPA** | 한국 표준 |
| 인증 | **Spring Security + JWT** | 클라이언트 분리 환경에 적합 |
| OAuth | **카카오 로그인** | 어르신 친화 (이미 사용 중인 계정) |
| DB | **PostgreSQL 16** | 오픈소스 RDBMS 표준 |
| 배포 | **Docker Compose + nginx** | 컨테이너로 어디서든 동일 동작 |

## 6. 시스템 구조

> AI 추론은 **브라우저에서 직접 수행**돼서 영상이 서버로 가지 않습니다.
> 백엔드는 **사용자, 운동 데이터, 기록만 다루는 가벼운 REST API**고, JWT 기반 stateless 인증을 사용합니다.
> nginx가 SPA fallback과 백엔드 API 프록시를 동시에 처리합니다.

## 7. 시연 (라이브)

> 실제로 한번 보여드리겠습니다.
>
> 1. 카카오로 로그인합니다
> 2. 출생연도 입력 모달이 뜹니다 → 연령대 선택
> 3. 홈에서 "앉아서 앞으로 나란히" 운동 선택
> 4. 카메라 안내 → 시작 버튼
> 5. 자세를 잡으면 카운트다운, 풀면 1회 카운트
> 6. 완료 → 결과 화면
> 7. 기록 보기에서 주간 추세 + 목표 진행바 확인

## 8. 향후 계획

> 캡스톤이 끝나도 다음 단계가 있습니다.
> - **연령대별 자동 운동 기준** — 출생연도 데이터를 활용해 70대 / 80대 가동 범위 자동 조정
> - **모바일 앱** — 반응형 웹은 됐고, 다음은 PWA / 네이티브
> - **공공기관 연계** — 보건소·복지관에서 활용할 수 있는 B2B 모델
> - **데이터 축적 + 분석 리포트** — 사용자별 진척도 그래프를 가족에게 공유

## 부록 — 기술적 깊이 (질문 대응용)

### Q. AI 모델 어떻게 선택했나?
> MoveNet Lightning은 0.54 GFLOPs로 매우 가볍습니다. 정확도가 높은 BlazePose나 PoseNet도 후보였지만, 어르신 PC나 저사양 기기에서 30fps 이상을 유지해야 했고, 브라우저에서 직접 돌릴 수 있어야 했기 때문에 MoveNet Lightning이 최적이었습니다.

### Q. 자세가 정말 정확히 측정되나?
> 운동마다 측정에 사용하는 관절 세 점이 다릅니다. 예를 들어 측면에서 측정해야 정확한 운동은 사용자에게 "옆쪽에서 카메라를 봐주세요"라고 안내하고, 정면 운동은 정면 안내가 뜹니다. 또 키포인트 신뢰도가 일정 이하면 측정하지 않고, EMA 스무딩으로 떨림을 줄입니다.

### Q. 보안은?
> 비밀번호는 BCrypt 해시 저장, JWT 토큰 기반 stateless 인증, 사용자별 기록은 DB 레벨에서 격리. 카카오 client secret은 백엔드만 보관하고 프론트에는 REST API 키만 노출됩니다. 영상은 서버로 안 보내니까 프라이버시 위험도 없습니다.

### Q. 어떤 부분이 가장 어려웠나?
> 자세 카운트 로직입니다. 처음에는 단순히 "정자세를 일정 시간 유지하면 카운트"로 만들었는데, 키포인트가 잠깐 가려지면 카운트가 잘못 올라가는 등 노이즈에 취약했습니다. 결국 rest → holding → satisfied 3단계 state machine을 만들고, 자세를 풀고 일정 시간 지속돼야만 카운트되도록 했습니다.
