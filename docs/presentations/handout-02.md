## 1. 다시 한 번 — CareFit이 무엇인가

지난 발표에서 자세히 설명드렸지만, 다시 한 번 짚고 넘어가겠습니다.

CareFit은 **사회적 약자가 가정에서 웹캠 하나로 재활 운동을 할 수 있게 돕는 AI 자세 피드백 웹 시스템**입니다. 별도 장비 없이, 안전한 가동 범위로, 실시간 피드백을 받으며 꾸준히 할 수 있는 것이 핵심입니다.

이번 발표에서는 **이 시스템이 실제로 어떻게 동작하는지**를 보여드리는 데 집중하겠습니다.

## 2. AI 자세 분석 — 어떻게 가능한가

### 관절 인식

저희 시스템의 가장 핵심적인 부분은 **MoveNet Lightning**이라는 AI 모델입니다. 이 모델은 카메라 영상의 매 프레임을 분석해서 사람의 신체 17개 키포인트를 추출합니다.

- 얼굴: 코, 양쪽 눈, 양쪽 귀 (5개)
- 상체: 양쪽 어깨, 팔꿈치, 손목 (6개)
- 하체: 양쪽 골반, 무릎, 발목 (6개)

저희는 얼굴 키포인트를 제외한 **상체와 하체의 12개**만 자세 판정에 사용합니다.

여기서 중요한 점은 이 모든 처리가 **사용자의 브라우저에서 직접 일어난다**는 것입니다. TensorFlow.js라는 라이브러리 덕분에 AI 모델이 사용자의 컴퓨터에서 돌아가고, 영상이 저희 서버로 전송되지 않습니다. 어르신들의 사생활을 보호하면서, 동시에 서버 비용도 들지 않는 구조입니다.

### 각도 계산

모델이 키포인트를 잡았으면, 이제 운동에 필요한 각도를 계산해야 합니다.

운동마다 측정에 사용할 **세 개의 관절점(A, B, C)** 이 정해져 있습니다. 예를 들어 "앉아서 앞으로 나란히" 운동은 **고관절-어깨-팔꿈치** 세 점의 각도를 잽니다. 어깨(B)를 꼭짓점으로 하는 각도를 코사인 법칙으로 계산합니다.

```
       cos⁻¹( (BA · BC) / (|BA| × |BC|) )
```

이 각도가 휴식 자세(0도)에서 목표(90도)로 변하는 흐름을 매 프레임 추적합니다.

### 두 단계 판정

여기서 저희의 핵심 차별점이 들어갑니다. 단순히 "정상 도달"만 보는 것이 아니라, **두 단계**로 판정합니다.

- 미달 → 빨간색 + 격려 메시지
- **허용 도달** → 연두색 + 성공 + 카운트
- 정상 도달 → 초록색 + 완벽 메시지

예를 들어 "앉아서 앞으로 나란히"의 정상 목표가 90도라면, 허용 목표는 60도입니다. 어르신이 어깨를 60도까지만 올려도 운동을 성공한 것으로 인정합니다. 무리하지 않으면서도 성취감을 느낄 수 있도록 한 설계입니다.

## 3. 자세 사이클 기반 횟수 카운트

운동의 본질을 다시 생각해 봅시다. "한 번"의 운동이란 무엇인가?

단순히 정자세를 일정 시간 유지하는 것이 아닙니다. **자세를 잡고, 일정 시간 유지하고, 다시 풀어서 처음 자세로 돌아오는** 일련의 사이클이 한 번입니다.

저희는 이 본질을 그대로 코드에 옮겨, **3단계 state machine**으로 카운트를 구현했습니다.

### State machine

```
[rest]   휴식 자세 / 운동 자세 미달
   │
   │ 운동 자세 진입
   ▼
[holding]   유지 중 — 영상 우상단에 카운트다운 (N → ... → 1 → 0)
   │
   │ 운동별 권장 시간 충족
   ▼
[satisfied] "충분해요! 천천히 내려놓으세요"
   │
   │ 자세를 풀고 400ms 이상 유지
   ▼
[rest] + count + 1   ← 여기서 비로소 1회 카운트
```

이렇게 만든 이유는 두 가지입니다.

**첫째**, 자세를 오래 잡고 있어도 1회로 셈됩니다. 다음 카운트를 받으려면 반드시 자세를 풀고 다시 잡아야 합니다. 이것이 운동의 본질에 부합하는 카운트입니다.

**둘째**, 노이즈에 강합니다. 카메라가 잠깐 흔들리거나 키포인트가 한두 프레임 누락되어도 그레이스 윈도우 300ms 안에서는 phase가 유지됩니다. 자세를 풀고 400ms가 지나야 비로소 카운트가 올라가기 때문에, 사용자의 의도와 무관한 가짜 카운트가 거의 일어나지 않습니다.

### 처음 만들었을 때의 문제

사실 처음에는 단순히 "정자세 0.8초 유지하면 카운트 +1, 1.5초 쿨다운" 로직이었습니다. 그런데 테스트하면서 발견한 문제가 많았습니다.

- 자세를 잡고 가만히 있으면 1.5초마다 카운트가 자동으로 올라감
- 카메라에 손목이 잠깐 가려지면 카운트가 잘못 올라감
- 빠르게 자세를 잡았다가 풀면 카운트가 누락됨

이런 문제들을 해결하기 위해 state machine을 도입했고, 지금은 노이즈에 강하면서도 사용자의 의도에 부합하는 카운트가 가능해졌습니다.

## 4. 유지 동작은 다르게 다룬다

모든 운동을 같은 방식으로 다룰 수는 없었습니다.

플랭크나 월 스쿼트 같은 운동은 "잡고 풀고 잡고 풀고"가 아니라, **한 자세를 가능한 오래 유지**하는 것이 본질입니다. 횟수가 의미가 없습니다.

그래서 저희는 운동마다 **rep 모드**와 **hold 모드**를 구분했습니다.

| | rep 모드 (28개 운동) | hold 모드 (플랭크) |
|---|---|---|
| 핵심 지표 | 운동 횟수 | 누적 유지 시간 |
| UI 표시 | "운동 횟수 N회" | "총 유지 시간 N초" |
| 사용자 동작 | 잡고 풀고 반복 | 한 번 잡고 가능한 오래 |
| 결과 화면 | 횟수 표시 | 분:초 표시 |

hold 모드에서는 자세를 잡고 있는 동안만 시간이 누적되고, 풀면 일시정지됩니다. 다시 잡으면 이어집니다.

## 5. 운동 가이드 — 어르신 언어로

각 운동마다 사용자가 이해할 수 있도록 4섹션으로 가이드를 만들었습니다.

- 📌 **준비 자세** — 어떻게 자세를 잡아야 하는지 한두 줄로
- 👣 **따라하기** — 단계별로 ①②③ 번호와 함께
- ⚠️ **주의 사항** — 노란 박스로 강조
- 💪 **어떤 효과가 있나요?** — 운동의 의미를 어르신 언어로

특히 신경 쓴 부분은 **의학 용어를 일상어로 풀어쓴 것**입니다. "오십견"이나 "어깨충돌증후군" 같은 용어를 그대로 쓰지 않고 "어깨 부딪힘", "어깨 통증 예방"처럼 풀었습니다.

또한 운동마다 **카메라를 정면에 둘지 측면에 둘지**를 자동으로 안내합니다. 측면 측정이 필요한 운동(예: 플랭크, 다리 들기 등)은 카메라 안내 메시지가 주황색으로 강조되어 사용자가 카메라 배치를 다시 한번 확인하게 만들었습니다.

## 6. 카카오 로그인 + 출생연도 입력

어르신들은 새로운 앱에 가입하는 것 자체를 어려워합니다. 그래서 **카카오톡 한 번 클릭으로 가입**할 수 있게 만들었습니다.

### 흐름

1. 사용자가 카카오 로그인 버튼 클릭
2. 카카오 인증 화면 → 동의 → 인가 코드 발급
3. 저희 백엔드가 인가 코드를 받아 카카오 서버에 토큰 교환 요청
4. 받은 access token으로 카카오 사용자 정보 조회
5. 신규 사용자라면 자동으로 가입 처리 (username은 `kakao_<id>`, password는 null)
6. 저희 시스템의 JWT 토큰 발급 → 클라이언트에 반환

### 출생연도는 왜 모달로 받는가

카카오에서 출생연도 정보를 직접 받으려면 **카카오 비즈 앱 검수**가 필요합니다. 사업자등록증이 있어야 하고, 학생 캡스톤 단계에서는 통과하기 어렵습니다.

그래서 저희는 **첫 로그인 후 강제 모달**로 출생연도를 받습니다. 1940년대부터 2000년대까지 10년 단위로 큰 버튼이 표시되고, 하나만 누르면 끝입니다.

이렇게 받은 출생연도는 향후 **연령대별 운동 기준 자동 조정**에 활용할 예정입니다.

## 7. 기록과 통계 — 꾸준함의 시각화

운동을 한 번 끝낼 때마다 자동으로 결과가 저장됩니다. 사용자는 기록 화면에서 자신의 운동 이력을 다양한 방식으로 확인할 수 있습니다.

### 기록 화면 구성

가장 위에는 **주 선택 컨트롤**이 있습니다. 이번 주뿐만 아니라 이전 주, 그 전 주의 기록도 모두 조회할 수 있습니다. 화살표를 누르면 한 주씩 이동하고, 최대 52주(약 1년) 전까지 거슬러 올라갈 수 있습니다.

그 아래에는 **피드백 메시지**가 한 줄 표시됩니다. 지난 주와 비교해서 "이번 주 5번, 지난주보다 2번 더 하셨어요!" 같은 문구가 동적으로 생성됩니다.

다음은 **이번 주 목표 진행바**입니다. 주간 운동 횟수와 시간 두 가지 목표가 막대그래프로 표시되고, 달성하면 ✓ 표시와 함께 카드가 초록색으로 강조됩니다.

그 아래에는 **요약 4카드**가 있습니다. 이번 주 운동 횟수, 시간, 평균 정확도, 그리고 연속 운동일 수가 한눈에 보입니다. 특히 연속 운동일 카드는 주황색 그라데이션으로 강조해서, 사용자가 "꾸준히 하고 있구나"를 강하게 인지하게 합니다.

다음은 **주간 추세 막대그래프**입니다. 월요일부터 일요일까지 일별 운동 횟수가 막대로 표시되고, 오늘 막대는 더 진한 색으로 강조됩니다.

마지막으로 **운동별 카드**가 있습니다. 어떤 운동을 얼마나 했는지, 정확도는 어땠는지를 운동 이름과 함께 카드 형태로 나열합니다.

### 목표 설정

기본 목표는 주 3회 / 30분입니다. 첫 가입 시 자동으로 설정되고, 설정 모달에서 언제든 변경할 수 있습니다.

## 8. 어르신 친화 UI

기능이 아무리 좋아도 어르신이 사용할 수 없으면 의미가 없습니다. 그래서 UI 측면에서도 여러 가지를 신경 썼습니다.

- **글씨 크기 토글** — 작게/보통/크게 세 단계로 직접 조절. PC와 모바일에서 각각 다른 픽셀로 매핑
- **차분한 세이지 그린** 색감 — 자극적이지 않은 톤
- **색상 기반 피드백** — 글을 못 읽어도 빨강/연두/초록으로 인지 가능
- **한국어 어절 단위 줄바꿈** — 단어 중간이 잘리지 않음
- **AI 생성 운동 일러스트** — 어떤 동작인지 직관적으로
- **로그아웃을 설정 모달 안으로** — 잘못 누르는 사고 방지
- **모바일 반응형** — 네비바가 화면 크기에 따라 점진적으로 축소

## 9. 라이브 시연

이제 실제로 한번 보여드리겠습니다. 다음 순서로 시연할 예정입니다.

1. 카카오 로그인 → 연령대 입력 모달
2. 운동 선택 화면에서 "앉아서 앞으로 나란히" 선택
3. 카메라 위치 안내 → 시작 버튼
4. 자세를 잡으면 카운트다운 → 자세를 풀면 1회 카운트
5. 운동 완료 → 결과 화면
6. 기록 보기에서 목표 진행바와 주간 추세 확인
