**제목**: CareFit — 최종 완성 + 배포
**부제**: 캡스톤 디자인 II 최종 발표

**대사**:

## 슬라이드 2 — 한 줄 요약 (재학습)

**대사**:
> CareFit은 **사회적 약자가 가정에서 웹캠 하나로 재활 운동을 할 수 있게 돕는 AI 자세 피드백 웹 시스템**입니다.
> 핵심은 별도 장비 없이, 안전한 가동 범위로, 실시간 피드백을 받으며 꾸준히 할 수 있다는 점입니다.

## 슬라이드 4 — 시스템 구성 (배포 아키텍처)

**도식**:
```
[사용자 브라우저]
        │
        ▼
┌──────────────────────────────┐
│  연구실 서버                  │
│  ┌──────────────────────┐    │
│  │  nginx 컨테이너       │    │
│  │  · React 정적 파일    │    │
│  │  · /api/* 프록시       │    │
│  └─────────┬────────────┘    │
│            │                 │
│  ┌─────────▼────────────┐    │
│  │ Spring Boot 컨테이너  │    │
│  └─────────┬────────────┘    │
│            │                 │
│  ┌─────────▼────────────┐    │
│  │ PostgreSQL 컨테이너   │    │
│  └──────────────────────┘    │
└──────────────────────────────┘
```

**대사**:
> 배포는 **Docker Compose 기반**으로 구성했습니다. nginx가 정적 파일을 서빙하면서 동시에 백엔드 API 프록시를 해주고, Spring Boot이 PostgreSQL과 통신합니다. 세 컨테이너가 한 줄의 명령어로 함께 뜨고, 시크릿은 환경변수로 주입돼서 코드와 분리됩니다.

## 슬라이드 6 — 기술적 성과

**불릿**:
- **AI 모델을 브라우저에서 직접 실행** — 영상이 서버로 전송되지 않아 프라이버시 보호 + 서버 부하 0
- **자세 사이클 state machine** — 노이즈에 강하고, 운동의 본질을 반영한 카운트
- **rep / hold 이중 모드** — 모든 종류의 재활 운동을 일관되게 측정
- **JWT + 사용자별 기록 격리** — Stateless 인증으로 확장성 확보
- **Docker 1-shot 배포** — 다른 환경에서도 동일하게 재현 가능

**대사**:
> 기술적으로는 다섯 가지 성과가 있었습니다. AI 모델을 브라우저에서 직접 돌린 점, 자세 사이클을 state machine으로 모델링한 점, rep과 hold 두 모드로 모든 재활 운동을 다룬 점, 사용자별 데이터 격리, 그리고 어디서든 한 줄로 띄울 수 있는 Docker 배포입니다.

---

## 슬라이드 7 — 사용자 경험 성과

**불릿**:
- 가족·돌봄 인력 없이 **혼자서도** 재활 운동 가능
- **잘못된 자세에 대한 즉각 피드백** — 부상 위험 감소
- "이번 주 N번 운동, 지난주보다 ↑" 같은 **동기 부여 메시지**
- 큰 글씨 / 색상 피드백 / 어절 줄바꿈 등 **노년층 접근성**

**대사**:
> 사용자 경험 측면에서는 어르신이 가족 도움 없이 혼자 운동을 시작할 수 있도록 모든 단계에서 친화적인 안내를 넣었습니다. 잘못된 자세는 즉시 빨간색으로 보여주고, 잘하면 격려 메시지가 뜹니다.

## 슬라이드 8 — 향후 발전 방향

**불릿**:
1. **연령대별 자동 운동 기준** — 70대·80대에 맞춰 ROM 자동 조정
2. **공공기관 연계** — 보건소·복지관 B2B 모델
3. **HTTPS + 모바일 카메라 안정화** — PWA 전환
4. **장기 데이터 분석 리포트** — 가족에게 진척도 공유
5. **수어/음성 안내** — 청각·시각 장애인까지 확장

**대사**:
> 캡스톤이 끝나도 다음 단계가 많이 있습니다. 출생연도 데이터를 활용한 연령대별 자동 기준, 보건소·복지관과의 B2B 연계, 그리고 청각·시각 장애인을 위한 보조 안내 같은 접근성 강화 방향을 그리고 있습니다.
